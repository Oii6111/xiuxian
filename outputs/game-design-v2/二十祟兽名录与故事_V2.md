# 《家族修真录》二十祟兽名录与故事 V2

版本：2.0｜原创世界：照生五域｜本文件是设计提案，20只Boss均未因名录生成而自动进入游戏。

共20只：1只教学Boss、15只五域祟兽（其中5只主祟）、2只旁篇祟兽、1只世界Boss、1只终章Boss。17个临床主题只提供创作灵感，3只纯虚构Boss无疾病对应。五行是美学与玩法语法，不是医学分型、疾病病因或治疗方案。所有妖名、神话故事与妖谱句均为原创。

旧五祟的核心造型与故事保留，并扩展其地图位置、NPC关系与终章作用。旧V1中的独立背景在此纳入常生仪失序的共同起因；这不是在解释现实疾病起因。

### b00 听雷｜序章试炼

- 地点：照生乡·渡劫台
- 临床主题：无，纯虚构；五行创作归类：无
- 形象：一只由云气、铜铃与纸符构成的小雷兽，蜷伏在旧灯座上。
- 战斗关键词：预兆识别与防御选择

**身世与人物关系**

雷叔用残存灯阵唤出听雷，教新守灯者辨认征兆。它并无恶意，只会把过早的躲闪、过晚的出手照在地面。青松留下的旧札写着：先看清，再出手。玩家完成三轮试灯，灯芯分出五条微光，乡外道路重新出现。

**招式与破解**

落雷有地面圈；镇心可抵挡；错误后显示原因。

**战后变化与奖励**

修复灯座，五域主线开放。

奖励：基础功法·镇心、照生灯。首通按独立结算记录发放，重试不刷主线钥匙。

**临床灵感与区分**

纯虚构游戏主题，不对应临床诊断。

**进入与生产状态**

新游戏教学可进入。

素材状态：concept_only，未建模/未接运行时。建议制作批次：P0。tier=0仅表示设计角色层次，不是现实疾病分期或固定难度门槛。

### b01 朽梁｜支线祟兽

- 地点：苍梧林·悬木栈道
- 临床主题：骨质疏松；五行创作归类：木
- 形象：一头背负古桥的木麋，外皮完整，梁腹却呈中空格架；不画断骨患者。
- 战斗关键词：承重分配与路线选择

**身世与人物关系**

阿禾的师傅曾为栈道画过逐梁检修图。村人只修补表面，直到搬运木料的车轮压出细响。朽梁在断脉后与栈道相接，将所有重量留给最薄的梁。玩家需要读图、迁移石块并加设支撑，才有安全空间接近它。桥修好后，师傅把检修图挂在入口，提醒后来人留意看不见的承受。

**招式与破解**

桥段有承重标记；开支撑机关；劫核显露后短战。

**战后变化与奖励**

安全栈道开放，苗圃运输恢复。

奖励：护架符、木桥外观。首通按独立结算记录发放，重试不刷主线钥匙。

**临床灵感与区分**

骨强度下降与骨折风险相关，骨折前常没有明显症状；关卡中的空心梁是结构隐喻。

参考：[NIAMS：骨质疏松](https://www.niams.nih.gov/health-topics/osteoporosis)。该来源只支持上述临床背景，不支持五行归类、神话因果或属性百分比。

### b03 窃荣｜主祟

- 地点：苍梧林·问春祠
- 临床主题：癌症；五行创作归类：木
