# 《家族修真录》散祟与乡人志 V3

本次新增10种小怪、6位乡民的程序化3D造型、真实战斗与战前/战后对白。整体沿用用户确认的Q版立体卡通＋斜俯视2.5D方向，不使用旧像素仙村。

## 世界中的位置

地脉受损 → 常生仪失去差异校准 → 五坛各自失序 → 守形灵成为区域主祟 → 散逸的行炁附在草木器物上形成散祟 → 乡人请求帮助 → 玩家在小规模清障中读懂预兆 → 处理主阵 → 散祟归巢、设施复建、乡人继续自己的生活。

这是神话创作的虚构因果；小怪不代表真实病原体、疾病病因、患者性格或亲属过错。部分主线恢复后，小怪回到故乡传送门周边作为和平住民，不以屠杀或病情恶化增加刷取收益。

## 小怪的玩法定位

每个五行地区两种小怪。对应的区域Boss场景先生成两只散祟，玩家用近身攻击、功法、护盾和闪避清障；小怪存在时主祟暂不叠加攻击。散祟退散恢复少量局内真气和体力，随后有短暂准备窗口再进入主祟机制。

小怪也有独立预兆和真实命中，伤害低于主祟。击败后取消它尚未触发的攻击，避免来源消失仍被伤害。每场只生成一次，不无限刷新。散祟图鉴幂等解锁，不额外刷首通经验。

## 闭环示例：玄泽

1. 汀兰说明墨沫混淆刻度、砂背找不到外池，玩家记下委托。
2. 进入玄泽任一区域篇章，先看墨沫的落点预兆，学会等锁定后移动；再观察砂背的砂环，知道中心不一定危险。
3. 小怪收拢后，真气和体力补充，主祟开始出招。
4. 壅川把落点与圆环放大为三碑蓄压；玩家开渠、避波、抓退水窗口。
5. 首通给水印与材料，玄泽传送门显示已复归，和平墨沫与砂背在附近出现。
6. 汀兰改用战后对白，玩家能把材料做成洞府石景，并继续下一域。
