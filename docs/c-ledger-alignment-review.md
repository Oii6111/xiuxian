## 4. 规则清单与交付接缝

`data/pixel-game-rules.v1.json` 从现有代码导出，标记 `authority = local_prototype_only`；不是服务端已接受的合同，也不是客户端可以上传的资产证明。

`rules_version = pixel-local-v1`、`catalogue_version = pixel-equipment-v1` 是本地交付标签，须由 C 登记/承认后用于正式协议。清单包含：

- 现有五档品质、四槽、五个模板的全部名称/属性/数值、70/700 价格。
- 首份五属性截断后均值、两组五档连续概率、先槽位后模板抽样、只提升十连末件的史诗保障、保留重复实例、没有累计保底。
- 共享日奖励、累计日规则、北京时间、本人与两老人、账号级灵宠。
- 20 Boss 的 ID/档位、四技能成本、命中回 5 灵力、两个不同首通解锁、每 4 个 Boss 境界推进；不设新门槛或次数限制。

C 可将这份清单用于规则移植及跨语言固定输入对照，不要求 Node 和 Godot 的随机种子产生相同序列。不要将五个模板平铺后等概率抽取。
