# 窃荣模型视觉精修记录

本轮目标：以原有四视图概念参考为造型依据，缩小实际 Blender 模型与参考图的差距，并检查 GLB 进入 Godot 后的视觉表现。

## 旧版差距的主要原因

旧版保留了鹿形、树角、叶鬃、铜饰和胸灯这些识别要素，但几何简化过多：枝角以直杆拼接，脸部采用圆球与凸眼，叶片近似平面，木纹以均匀凸条代替，肩甲缺少实心甲片。它呈现出粗略玩具模型的观感，与参考图的古木曲线、鹿脸神态和层叠材质差距明显。

灯光和材质会影响颜色、阴影与质感，但不足以弥补轮廓和结构差异。增加面数也需要服务于具体造型，不能只在原有简单形体上细分。

## 本次验收重点

1. **枝冠轮廓**：主干连续弯曲、向两侧展开，分叉有前后关系且逐渐收尖；叶簇附着枝端。先以纯色剪影检查是否接近参考的古木鹿角。
2. **脸部神态**：脸形收窄，口鼻浅长，眼形为内嵌杏眼，眉脊和颊骨有过渡；缩小圆鼻，耳片增加厚度和内凹结构，减少圆头、凸眼的小狗观感。
3. **叶鬃层次**：叶片有曲面、中央隆起与下垂尖端，大中小叶错位重叠，形成完整胸颈披肩，遮住基础体块连接。深浅青绿分层，并用少量金色叶脉连接细节。
4. **木躯与木纹**：提胸、收腹，木纹围绕躯干和臀部生长，包含旋涡、结疤与分叉；苔藓和短叶分布不规则，避免等距平行凸条。
5. **铜饰与胸灯**：肩甲有青玉底片、宽铜边和回纹面积；护踝覆盖腿面。胸灯具有分层金托、清晰切面和内外明暗，不能仅以线圈和少量尖叶代替完整装饰。
6. **材质与游戏内表现**：深木、青绿、象牙白与铜金分区清楚；表面具有适当的粗糙度与凹凸变化。Blender 专用程序纹理若参与最终效果，应烘焙为可导出的贴图，再检查 GLB 在 Godot 中是否保留。

## 验收顺序与待补记录

按“灰模剪影 → 同角度脸部与叶鬃 → 材质和灯光 → Godot 相同取景”推进。最终同时检查全身轮廓与局部细节，避免通过更近的镜头或更柔的灯光遮盖结构差距。

## 本轮完成与实测

已重建连续鹿脸和杏眼、弯曲枝冠、八层错位曲面叶鬃、木躯旋涡纹、实心肩甲及护踝，补分蹄与背部苔藓。复查修正眼部悬浮、头顶端面未封闭和枝冠过于等距的问题。每轮检查使用实际网格，原概念图没有改动。

新版86,914三角面、15个材质分区、7骨骼，GLB为6,671,720 bytes。相比旧版17,560面，细节和资源体积均有明显增加，尚未完成低端移动设备性能验收。木纹有1024像素颜色与切线法线贴图，已导入Godot。Blender源文件保留可编辑网格、UV、贴图和三段动作。

验证：Godot4.7.2，234项战役、61项旧版和57项资产检查，共352项通过，0失败。新增检查确认木纹颜色贴图、法线和UV进入游戏；另检查GLB只有一个皮肤、骨骼正确、三段动画保留。实际Godot近景与战斗截图生成成功。

- [Godot近景](screenshots/qierong-v2/godot-showcase.png)：真实GLB、可旋转镜头、中性光照。
- [Godot战斗画面](screenshots/qierong-v2/godot-combat.png)：保留正常玩法镜头，模型名牌已移高避免遮住枝冠。
- 在Godot单独运行scenes/qierong_showcase.tscn可检查模型。左键拖动旋转、滚轮缩放、1/2/3/4切换观察方向。
- 运行tools/blender/refine_qierong.py后调用build(publish=True)可重建正式资源；脚本在新场景制作，保留已有场景。render_views()输出实际四视角图。

仍存在的差距：参考图的古木枝节、细密叶脉、铜饰雕刻、宝石通透和精细表面纹理更丰富；当前版本没有逐处复原这些细节。Godot兼容渲染的实时阴影、金属反射与Blender路径追踪仍不同。改善已经体现在实际几何和导出材质上，不能据此宣称与概念图完全一致。
