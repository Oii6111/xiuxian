# 二十关 Boss 战斗与动作设计

问道长廊有二十个独立试炼场景，可直接选关。每个 Boss 有一招结合场地和故事的招牌技，门前给出线索，入场给出反制提示。部分设计从疾病机制取材，并用风路、机关、矿晶等虚构事物演绎。病理灵感和参考来源见 [五域设定资料](../data/pixel_campaign_bosses.json)。

## 二十关机制与反制

| 关卡 / Boss | 招牌技 | 场地变化与应对 |
|---|---|---|
| 1 听雷 `b00` | 两响照灯 | 第一响落在雷环，站在环心或环外。终阶段多一响中心雷，留在环心的玩家要及时退出。 |
| 2 朽梁 `b01` | 承重断梁 | 两侧桥梁依次开裂，短时留下余震。走中间桥板，终阶段再横移避开断裂纵梁。 |
| 3 涩节 `b02` | 锁轴扣诀 | 横向铁榫命中会扣灵力，之后转轴在本体周围回弹。先走上下，再远离本体。终阶段留意锁住原位置的竖线。 |
| 4 窃荣 `b03` | 夺生根脉 | 固定根脉吸中才回血。第二阶段起长出大小不同的木身。横移、踏云或完全格挡阻止吸血，趁萌芽清理分身。 |
| 5 乱律 `b04` | 错拍三震 | 十字与鼓环紧接，终阶段的圆形重击则延后。看每次新预警，给迟拍留出闪避。 |
| 6 窄焰 `b05` | 换廊压焰 | 火压从上廊换到下廊，安全路随之换边。终阶段火势挤向中央，留在边路。 |
| 7 赤棘 `b06` | 赤晶合棘 | 两簇晶体先落地，之间随后引爆，击中会短时减速。离开横向晶线，终阶段斜移避开余晶竖爆。 |
| 8 积璧 `b07` | 璧壳层叠 | 外壳与内壳逐层收拢，最后才合上渠心。看清当下亮起的环带，越过边缘再靠近。 |
| 9 薄丹 `b08` | 灯尽余息 | 暗灯落点和扬起的灯灰命中会扣体力。用走位离开原落点，为后续留一次踏云。 |
| 10 失稷 `b09` | 四渠错流 | 西渠和东渠依次在不同交口泄流，终阶段加一道斜贯全场的末渠。绕开亮起的交口，及时换边。 |
| 11 闭岚 `b10` | 重岚封道 | 两侧风道同时封住并留下余势，中间留通路。终阶段中闸也会落下，沿中央通路绕到闸的左右。 |
| 12 灼羽 `b11` | 回雁热雾 | 火鹭沿两条交叉斜线往返，命中带减速。离开折返线，终阶段让出斜线交会处。 |
| 13 缄风 `b12` | 缄风吞翎 | 宽扇先吸近，窄扇再吹飞，伤害在落地时结算。横移出扇面或踏云穿过风边，也能用云罡挡住吹飞、减轻落地冲击。 |
| 14 沉砂 `b13` | 浊砂沉池 | 砂圈落地后变成会伤人的泥池，首击还会减速。每次换去空地，保留返回本体的路线。 |
| 15 滞潮 `b14` | 双汐错拍 | 双轮轮流泄潮，首道带余势，第二道从反侧回流。等第一轮过去再换边，终阶段避开合潮交汇。 |
| 16 壅川 `b15` | 三碑量压 | 西岸、中槽、东岸按顺序涨水。先离开当前量水碑标出的区域，终阶段退到两岸避开决堤水线。 |
| 17 漏夜 `b16` | 漏刻回环 | 余灯一路亮起，末拍回到最初落点。记住开场那盏灯，绕开回环再反击。 |
| 18 失简 `b17` | 灯签引路 | 渡口、茶杯、归家灯签依次指明墨环的空心。照当前灯签走进圈里，或退到墨环外。 |
| 19 晦鳞 `b18` | 镜海叠痕 | 第一阵锁定角色起手位置，第二阵在场地另一侧映出对应的十字，命中会短时减速。避开镜像落点，末段沿斜角避开合镜。 |
| 20 执衡 `b19` | 五印轮值 | 木圈、火线、土十字依次出现，后两阶段再加入金风门和水印环。看印次换走位，等天仪停转再出手。 |

关卡下标为 `i = 0…19` 时，Boss 固定生命为 `3200 + 720i + 8i²`，基础攻击为 `(34 + 4.5i) × 1.25`，破势上限为 `140 + 5i`。角色基础生命为 100，装备额外叠加。普通招式的原始伤害由基础攻击、招式倍率和出招时阶段决定，最高 240。招牌技各段再按自己的倍率结算，之后应用角色防御、护盾和受击保护。

## 可读的攻守节奏

Boss 根据距离、玩家速度、上次用招和招式等待次数决定追近、侧移、拉开及选招。蓄力开始时固定方向、落点、几何、持续时间和伤害；少量提前量只在此时计算，后续换阶段也不修改正在显示的攻击。

1–4 关三阶段分别为 1/1/2 段；5–12 关为 1/2/2；13–20 关为 1/2/3。段间 .42 秒移位，每击都有完整预兆；完整收招至少 1.05 秒，每多一段再增加 .22 秒。各关最短蓄力下限从 .84 秒逐步降至 .66 秒，实际还取配置蓄力与阶段修正的较大值。

普通招式依靠起手、朝向、特效与音效提示。冲锋使用连续胶囊扫掠，每次冲锋最多命中一次。扑击在落地时结算，弹幕在弹体抵达时结算。招牌技在地上标出即将生效的区域和段号，同一拍的多个区域同时出现。预警边线与命中共用场地裁剪后的几何。后续攻击按顺序亮起，残留区域也有独立标记。

招牌技中的泥砂、热雾或赤晶命中后可减速 1.65 秒，暗灯扣除 24 体力，锁诀扣除 18 灵力。闪避和完全格挡可防住这些命中附带的效果。缄风的吸入段只移动角色，之后的吹飞约持续 .62 秒，玩家仍可在空中用云罡抵挡落地冲击。

带余势的招式以 .6 秒为周期检测仍站在区域内的角色。散祟独立追击，常规散祟蓄力 .72 秒、扑击 .16 秒到达才命中，然后回退与收招 1.45 秒。受击保护 .5 秒，完全格挡保护 .22 秒。

窃荣的「夺生根脉」先锁定方向，再连续释放脉冲，最后一阶段由两次增加到三次。实际扣到角色气血才会为窃荣恢复生命，横移、闪避或完全格挡都能阻止回血。第二阶段开始定期长出木身，小木身移动更快，大木身较耐打且扑击范围更大。同场最多四只，第三阶段增殖更快。

## 招牌技配置

[基础招式配置](../data/combat/pr4_boss_moves.json)保存移动、倍率、选招和连段节奏。[招牌技配置](../data/combat/pr4_boss_signatures.json)用 Boss ID 查找记录，`move` 指向要改造的原招式 ID。每条记录包含招名、门前线索、反制提示及 `beats`。窃荣保留原配置里的吸血比例与分裂间隔。

`beats` 按出招时钟升序排列。每段的 `at` 是蓄力结束后经过的秒数，`stage` 是该段开放的阶段下标（0 至 2）。`anchor` 可以取 Boss 起手位置、蓄力时锁定的角色位置或场地中心。`mirror` 取角色锁定位置关于场地中心的镜像。`shape` 支持圆、环、直线、十字和扇形。用 `offset` 定位区域，用 `radius` 和 `width` 指定大小。直线再用 `from` 定位起点，扇形的 `width` 表示以弧度计的半角。相同 `at` 的区域属于同一拍。

每段还可设置伤害倍率 `scale`、提示 `label`、余场时间 `residue` 及命中效果 `effect`。`pull` 用于无伤吸近，`launch` 用于腾空及落地结算，`slow`、`fatigue`、`seal` 分别影响移动、体力和灵力。修改拍点后应同时检查相邻安全区之间的距离与可用走位时间。

## 真正的动作帧

20 个 Boss 每只 16 帧：四帧行走 / 游动 / 扇翼、四帧肢体攻击、四帧施法、两帧受击、失衡、倒地。四足兽交替迈腿并抬爪 / 踏蹄；鸟虫摆动足翼；蛇、鱼、蚌及悬浮神像按原身体结构设计，不为它们强加四肢。男女角色各 16 帧，覆盖行走、挥剑、剑诀、翻身闪避、受击和待机。

另有 8 类、每类 4 帧的栅格特效：剑弧、雷电、火晶、水浪、藤木、岩砂、月光、金印。当前使用 24 张图集、384 个实际绘制帧，另保留历史修订原图。使用内置 imagegen 生成，原图及精确提示词保存在 assets/combat_animations；运行图集以固定比例和显式脚底锚点打包，保留透明边距，清除切格混入的细小相邻碎片。

每种动作目前是四个关键帧，属于像素风分帧动画。角色变化来自实际重绘的肢体姿态；本版具名 Boss 不再依赖整图拉伸和 UV 扭动表现走路。腾空位移仍由真实攻击时序驱动。P 暂停冻结战斗时钟与动画，命中有 35–55 毫秒停顿、浮字和世界层轻震动；八种音效由项目脚本原创合成。

## 操作与验收

WASD 移动，J 普攻（可按住）、1 剑诀、2 / Space 闪避、3 / K 护盾、4 / R 归元、P 暂停、Esc 返回长廊。普攻 .12 秒、剑诀 .16 秒后进入命中帧才结算；攻击期间移动为 65%。翻身在 .18 秒内连续移动 145，保留 .30 秒无敌。详细反击、破势与对照数据见 [战斗玩法说明](CHALLENGE_COMBAT.md)。

运行 `tools/test_pr4_integration.ps1 -Graphical` 可检查全部二十个 Boss 的三阶段与六十招、完整对战、实际渲染、存档恢复、家族隔离、聚宝阁装备与生命周期。战斗设计测试另检查招牌技的时序与锁定预警，以及缄风的吸近、腾空、落地和防御。自动对战使用 100 基础生命、装备模板和内部碰撞数据，真人难度仍需通过实际试玩判断。渲染预览位于 `outputs/combat-lifecycle/boss-polish`。

战斗不增加灵石，不解释健康资料，也不将胜负转换为现实康复、闭关或飞升。游戏首通 / 最快记录按角色保存，当前规则版本 pr4_actions_v4 与旧版本分开。正式权威战果交给 C 对接，生命周期继续使用 A 的迁移规则与服务端确认边界。
