# 数据映射模型说明

这份文档说明：健康资料入口**采用了哪些数据**，以及这些数据**如何换算成游戏的初始人物状态**（属性）。

面向对象：游戏开发 / 产品 / 希望了解「为什么长辈的血压会变成这个灵力值」的任何人。

---

## 1. 采用的输入数据（三类）

入口把「图片 + 文字」汇总成一份结构化 document，只取下面三类常规数据：

| 来源 | 字段 | 说明 |
| --- | --- | --- |
| 体检报告图片 | `groups[].items[]` | 常规体检指标（血常规、血糖血脂、肝肾功能、血压心率、BMI 等） |
| 病历 / 文字病史 | `history[]` | 疾病史：`condition`（病名）、`onset`（起病时间）、`status`（ongoing/past/unknown） |
| 用药单 / 文字用药 | `medications[]` | `name`（药名）、`dose`（用法）、`purpose`（用途，如 降压/降糖）、`status` |

**筛选原则**：只保留能命中下面「身体系统关键词白名单」的常规指标；罕见、非常规的专科检查（基因检测、罕见肿瘤标志物、特殊免疫指标等）**自动舍去**。

---

## 2. 核心对应关系：身体系统 → 游戏属性

这是整个模型的核心。每个**身体系统**直接对应一个**游戏属性**，识别出的指标 / 病史 / 用药按关键词归到某个系统，去测算对应属性。

| 身体系统 | 对应属性 | 覆盖的常见数据（关键词举例） |
| --- | --- | --- |
| 心脑血管 | 灵力 `spirit` | 血压、心率、心电、心脏、高血压、冠心病、降压护心药 |
| 呼吸系统 | 防御 `defense` | 血氧、呼吸、肺、胸片、哮喘、慢阻肺、止咳平喘药 |
| 泌尿骨骼 | 体力 `stamina` | 肾、肌酐、尿酸、尿检、骨密度、痛风、护肾利尿药 |
| 代谢糖脂 | 身法 `speed` | 血糖、血脂、转氨酶、肝、糖尿病、脂肪肝、降糖降脂药 |
| 营养血象 | 气血 `hp_max` | BMI、体重、血常规、贫血、胃、护胃补铁药 |

> 关键词完整清单在 `rules.py` 的 `SYSTEMS` 里，改对应关系只动那里。

---

## 3. 每个属性怎么由具体数据算出（核心公式）

每个身体系统对应的属性，用**识别出的具体数据**直接加减：

```
属性分 = 系统基础分 + 正常指标×4 − 异常指标×6 − 持续病史×5 + 正在用药×3
```

| 数据 | 说明 | 对属性的调整 |
| --- | --- | --- |
| 正常指标 | 如「血压 128/80（正常）」 | +4 |
| 异常指标 | 如「血压 152/95（偏高）」「肌酐 128（偏高）」 | −6 |
| 持续病史 | `history` 中 status 为 ongoing/unknown 的疾病 | −5 |
| 正在用药 | `medications` 中对应的长期用药（说明正在管理） | +3 |

各系统**基础分**不同：

| 系统（属性） | 基础分 | 最终范围 |
| --- | --- | --- |
| 心脑血管 → 灵力 | 50 | 20–85 |
| 呼吸系统 → 防御 | 50 | 20–90 |
| 泌尿骨骼 → 体力 | 50 | 20–90 |
| 代谢糖脂 → 身法 | 50 | 20–80 |
| 营养血象 → 气血 | 80 | 40–100 |

气血（HP）基础分 80、上限 100，所以健康长辈气血在 80 上下，最多 100。

> 调整幅度都很小：异常只做 −6 这类小幅下调，**不会把老人角色写成残血**。

> 每个指标 / 病史 / 用药只会归入**一个**身体系统（按最长关键词命中），避免同一个药因字符串子串被重复计入多个属性；药名以**通用名**为准，商品名/品牌名不参与映射。

---

## 4. 其余 4 个属性怎么算

| 属性 | 由什么决定 | 说明 |
| --- | --- | --- |
| 攻击 `attack` | 活动能力 | `attack = 25 + 0.5×活动能力`；出现「卧床/偏瘫/活动受限」等活动能力下调到 40，攻击随之降到 45 |
| 洞察 `insight` | 资料完整度 | 有效指标 + 病史 + 用药越多越高 |
| 心志 `mind` | 家族支持 | 首次注册默认中性 50 |
| 气运 `luck` | — | 固定 50 |

---

## 5. 完整流程

```
体检报告图 + 病历图 + 用药图（多张）
        ↓ 视觉模型识别（recognizer.py）
结构化 document：groups + history + medications
        ↓ 规则引擎（rules.py）
具体指标/病史/用药 → 身体系统 → 对应属性
        ↓
10 个属性 + 守护准备度（readiness）
        ↓
baseline JSON（游戏读取）
```

---

## 6. 快速对照示例

输入：`血压 152/95（异常）`、病史 `高血压 ongoing`、用药 `氨氯地平（降压）`

- 「血压 / 高血压 / 氨氯地平」都命中**心脑血管** → 对应**灵力**
- 灵力 = 50（基础） − 6（血压异常） − 5（高血压病史） + 3（氨氯地平在管理） = **42**

再比如 `血糖 9.8（异常）` + `二甲双胍`：

- 「血糖 / 二甲双胍」命中**代谢糖脂** → 对应**身法**
- 身法 = 50 − 6（血糖异常） + 3（二甲双胍） = **47**

这就是「具体体检数据 → 具体属性」的完整对应链：**血压高 → 灵力降，血糖高 → 身法降，血氧低 → 防御降，肌酐高 → 体力降，贫血 → 气血降**。
