# 照生五域：像素篇章与叙事闭环

本篇章接入现有像素仙村。玩家仍从有住房、家人、田地和晨昏的村庄出发；新增内容使用同一像素画风，把二十名主祟、十类散祟、五域地图和战斗编成可往返的故事。旧版三维项目中的角色视觉描述与背景保留为设定资料，运行时由像素资源呈现。

## 这一次为什么出门

照生乡的五盏归灯已经很久没有一起亮过。父亲青松把家中那盏门灯留给年轻的守灯者，自己继续照看药圃、家谱与乡人的日常。他说：“不必把世间变得永远晴朗，只要让人还能找到回来的路。”玩家因此启程：修复被长夜打断的水路、农仓、信道、工坊与苗圃，带回五枚归衡印，让家乡重新拥有有变化的四季。

玩家是新一代守灯者；青松是父亲，雷叔是渡劫台的引路人，三者分别承担主角、家族牵挂与战斗导师的角色。家族健康演示继续属于原有村庄界面。新篇章只显式接收昵称与头像；首次进入不继承旧档资源、诊断字段或疾病标签。

长夜的源头是执衡曾立下的愿：“不再有一次失去。”他把五行阵封成不会轮转的无隙殿。原本维持生活的行炁失去边界，工料、飞鸟、纸屑和泉砂化成散祟；更大的停滞聚成主祟。主角最终要解除这份不可能的许愿，让变化重新流动。执衡有可理解的动机，但他的绝对静止让乡人失去了生活的余地。

## 每次出门都有一个看得见的结果

流程是村庄接到人物线索 → 地图选定篇章 → 看见目标与预兆说明 → 收拢两类散祟 → 操作场景阵眼 → 应对主祟招式并反击 → 结算首通成果 → 回村听见新对话、看见区域复明。木、火、土、金、水可以自由选择先后；每域内部先解生活难题，再处理主阵。

听雷教学要求成功避开或挡住一次预兆。区域战先清散祟，散祟存在时主祟护障不受伤；散祟退散会返还少量真气与体力，随后主祟才开始连续出招。所有非教学关需完成全部场景目标才解除主祟护障，并制造短暂反击窗口。普通阵眼可以靠近操作或打破；护灯只能靠伴行抵达，不能用打阵眼或普通交互代替。失简使用始终可查的固定路标顺序，灼羽增加伴行护灯。

首通给固定修为、营建材料和持久的故事旗标。门灯需完成试灯并花 3 材，药圃需首印与 9 材，听雨亭需三印与 15 材，观星台需终章与 24 材，让远行在家中留下分阶段的变化。核心首通给归衡印，回村能查看对应散祟的安置故事。失败、退出和练习不扣家族资源；再战可以更新按难度、演示预设与功法分别记录的最佳时间，不重复发放首通材料。驱动力来自“我读懂了一招”“我让一段路重新通了”“家里有人记得我做过的事”，以及下一段可选择的旅途。

## 散祟不是无名的消耗品

每域两类散祟是主祟机制的简短预习。它们先各自做出清楚的预兆，退散后再进入主祟阶段，避免初学者同时面对多套复杂规则。收拢与回家安置构成图鉴闭环；完整故事、招式、回乡结果及关联 Boss ID 保存在 `data/pixel_campaign_minions.json`。

| 地域 | 散祟 | 预习与回家故事 |

| 木 | 蔓芽／纸蠹 | 细藤直线与纸圈落点；嫩芽归苗盘，旧家书整理后给纸蠹留下废纸边 |
| 火 | 炭尾／晶蹄 | 火线与落圈的辨识；炉火有边界，幼兽有安全石圈 |

## 进度旗标与实现边界

状态以 `schema: 3` 保存到独立的 `pixel_five_realms_v1.json`。Windows 默认目录是 `D:/Projects/Codex/user-data/xiuxian/pixel-campaign/`；可用 `XIUXIAN_PIXEL_CAMPAIGN_SAVE_DIR` 改目录，测试用 `save_override`。旧村庄和三维篇章存档不被自动读取或覆盖。

每次首通记录 `cleared_bXX`；教学记录 `village_lamp_lit`；五域核心分别记录 `region_木_restored`、`region_火_restored`、`region_土_restored`、`region_金_restored`、`region_水_restored`；齐印记录 `five_seals`；终章记录 `finale_complete`。世界、地图和对话依这些旗标呈现复明与前后文。旁篇、共域在任一域恢复后可进入；终章要求五个核心的实际通关记录，单独改动印章显示不能解锁。

原设定资料中的技能改装、快速旅行、独立节律练习、灌渠小游戏、多人共守、同伴机关及季节模拟是后续扩展钩子；当前篇章以可游玩的地域选择、战斗、故事查看、首通变化和回村循环承接这些叙事，不把设定文字当成已经交付的独立子系统。

战斗的护元、攻击、敌方护障及阶段都是游戏数值。演示预设只有未知、平稳、疲倦三档，并在入场时复制固定快照。它不读取人体生理数据，也不推断玩家是否患病；击败带疾病创作灵感的主祟不会改变现实疾病状态。健康行为、现实记录与就医信息在村庄对应模块中独立表达，玩家不需要提交诊断才能游玩。

## 验证方法

`tests/pixel_campaign_rules_test.gd` 只加载数据与纯逻辑，检查二十名角色资料、唯一 ID、五域链式解锁、免费重试与首通幂等、五印终章、存档隔离、预兆判定、教学与护灯目标，并以公开战斗操作模拟完成全部二十战。模拟控制器每帧可以直接给出位置，所以该测试证明规则与数据可通关，不代表真实移动耗时、难度平衡或最终美术质量；这些由实际场景的试玩与截图补充验证。
