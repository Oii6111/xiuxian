## 空间与判定

encounter.gd在X/Z平面用Vector2进行确定性计算，world.gd将同一组参数生成3D地面预警。circle是落点圆盘；line/charge是带端圆的线段；ring有安全中心；cone使用方向和夹角；cross/corridor/pulse/roots由这些基本形状组合。角色有约0.25的碰撞余量，地面接近边界时应及时离开。

预警先显示，实际命中在预警结束后判定；每个攻击区域对同一角色只结算一次，并有受伤后的短暂保护，避免交叉区域重复扣血。护盾与闪避均在实际命中时有效，不仅播放特效。故事模式的预兆与护元更宽裕。

## 可破解机制

一般阵眼可E操作或近身攻击两次；仅在距离足够时有效。失简必须按“渡口→茶杯→归家”的常驻日志提示处理，不按错扣资源。灼羽有可见羽灯伴行，护送到对侧会完成阵眼；也可自行处理散雾口。阵眼减少护障，完成后开放更强反击窗口。

这是统一战斗底座上的20个原型篇章，已实现多种形状、20套资料、差异化目标与全部关卡入口。复杂独立AI、逐帧角色动画、完整多地区自由探索和联网共守仍属于扩展工作，不将原型说成20套完成商业制作的独立资产。
