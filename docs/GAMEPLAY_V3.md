# 照生五域 · 可玩版本 V3

用户已确认：Q版立体卡通，接近轻快明亮的3D游戏观感；固定斜俯视形成2.5D操作，不沿用像素仙村。当前造型用Godot原生网格程序化创建，属于可迭代的立体原型，不把它当作完成精修的商业模型。

## 1. 实际游玩闭环

选择形象与名字 → 听雷教学实际躲避/格挡 → 在六位乡民处了解委托 → 任选五域 → 小怪清障与招式学习 → 处理阵眼、观察Boss、抓窗口 → 固定首通奖励 → 材料布置洞府、乡民战后对白、和平小怪归巢 → 下一域或个人最佳练习。

五行与真实疾病仅通过创作主题相联；现实数据不作为进入剧情的门票。小怪没有现实病种，不把患者变成敌人。

## 2. 每类角色的作用

- 年轻守灯者：玩家操作者与形象。
- 家族命影：界面显示青松真人，承载模拟状态快照；当前还没有接入真实健康平台。
- 散祟：由逸散行炁附在草木器物上形成，原型化机制比Boss简单、伤害更低。
- 区域主祟：控制整片失序场景，玩法是小怪机制的组合与放大。
- 乡民：委托、解释与战后生活的主人，玩家归来后他们继续做自己的事。
- 执衡：收回五印后面对的旧执行机关。结局恢复各地不同节奏，不承诺现实“永远无病”。

## 3. 激励规则

短时：明确命中反馈、护盾挡住、闪避成功、散祟退散补充真气与体力。
单场：完成阵眼解除护障，获得稳定反击窗口；失败能知道哪一招命中，可立即免费重试。
首通：固定修为和材料，五主祟给永久归衡印；不随机卡关键掉落。
回村：可花材料安放门灯、石景、谷亭、风铃；恢复地区的小怪作为和平住民出现，NPC对白改变。
长期：五印终章、完整Boss与散祟图鉴、个人最佳时间。记录按难度、功法与模拟状态分开，避免不同配置直接比较。
重复练习不重复发首通XP或印，不依赖长辈追加健康记录。当前主要是有限内容的完整进度循环，不假称已做成持续运营MMO。

## 4. 攻击与可读性

底层形状：落点圆、线段/冲撞、环、扇形；组合成十字、双侧走廊、间隔脉冲、根须连线。实际命中使用与3D地面预兆相同的空间参数，并考虑角色半径。
预兆结束后才命中；重叠区域之间有短暂受伤保护。小怪未清时不叠加Boss主招，避免一次要求识别太多信息。小怪被击败会取消其未完成攻击。
一般阵眼可近距E操作或近身击破；失简保留常驻顺序提示，错误不扣资源；灼羽提供可见的护送羽灯与替代机关处理。
每个角色的故事、招式和模型族由JSON索引，实际攻击与数据分离便于策划调整。

## 5. 自由度与状态

五域推荐水土金火木，但教学后可选任何一域。两只支线祟兽不作主祟硬前置；五印才锁终章。
故事模式预兆更长、护元更多，标准模式更紧凑。可以选雷诀、镇心或分流。所有模式都能看完整故事。
未知模拟状态用默认系数并注明未判断；模拟稳定和疲劳只演示下一场攻击/体力差异，不决定Boss现实严重度。进入战斗后快照固定。
旧存档保留，新存档独立且有备份；不会以游戏胜负修改旧恢复记录。

## 6. 当前范围

已可在Godot4运行20个Boss、10种散祟、6位乡民、五域入口、机关反制、奖励、家园与终章。五域以不同配色与装饰的竞技场及故事面板呈现，尚非五张完整开放探索大地图。程序化模型可替换为后续精修资产；真实健康接口、临床判定、复杂巡逻群AI、多人共享与浏览器导出包另行开发。
